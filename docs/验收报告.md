## 轻量化与零依赖（本轮重点）

| 项 | 优化前 | 优化后 | 说明 |
|---|---|---|---|
| 外部依赖 | 需要系统预装 WebView2 | **单 exe 自带引导器** | exe 内嵌 1,876,736 B 官方引导器（SHA256 `f414de01…`），缺失时自动静默安装 |
| release 产物 | 16.1 MB | **6.9 MB** | `opt-level="z"` + LTO + `codegen-units=1` + `panic=abort` + strip |
| Rust 依赖 | 含 anyhow / tempfile / tracing / tracing-subscriber / quick-xml / dirs | 已移除 6 个 | 前四个未使用；quick-xml 换成 20 行正则；dirs 换成环境变量解析 |
| 死代码 | 7 个未使用函数 | 已删除 | `count_files` / `zip_contains` / `ensure_java_for` 等 |
| 启动耗时 | 启动即全盘扫描 Java（注册表 + 多个目录 + 逐个 probe） | 移除，改为按需 | 首屏实测 0.2s；`setup 完成` 日志 624ms 为冷启动含 WebView2 初始化 |
| 前端体积 | — | 328 KB JS（gzip 100 KB） | Tailwind purge；无重型组件库 |
| Tauri features | 默认全开（含 x11/dbus/dynamic-acl） | 仅 `wry` + `compression` + `common-controls-v6` | Windows 上 x11/dbus 无意义；不使用运行时 ACL |
| 可访问性 | 无焦点样式、动画不跟随系统 | 焦点环 + `prefers-reduced-motion` | 纯 CSS，零依赖 |
| 重复哈希 | 每次安装重算 SHA1 | 内存缓存（路径+大小+mtime） | 大文件/重复安装明显更快 |
| 运行时依赖 | .NET / VC++ / Java 均不需要 | 保持 | UCRT 属 Win10+ 系统组件；Java 由启动器自动下载 |

**边界**：若目标机器 **没有网络且没有 WebView2**，内置引导器无法完成安装；此场景需要离线安装包（可后续提供 NSIS + WebView2 offline installer，体积约 +130MB，与"轻量"冲突，故默认不做）。

**未新增任何功能**：本轮只做瘦身、去死代码、补诊断与 UI 验证，联机与 CurseForge 仍为空壳。

## 新增功能说明

### 服务端（C21）

- **拖入识别**：压缩包含 `server.properties` / `eula.txt` / `start.bat` / `user_jvm_args.txt` / `libraries/` 即判定为服务端包；从 `manifest.json`、`mmc-pack.json`、`forge-*-installer.jar`、`neoforge-*-installer.jar`、`libraries/net/minecraftforge/...` 推断 MC 版本与加载器。
- **安装**：解包 → 提升 `overrides/`、`.minecraft/` 层级 → 原版下载 `server.jar`、Fabric 下载服务端启动器、Forge/NeoForge 运行 `--installServer` → 生成/读取 `server.properties` → 写入 `server.json`。
- **启动**：按加载器选择参数（`-jar server.jar nogui`、Fabric launcher、Forge `@libraries/.../win_args.txt`），注入 `-Xmx`，管道采集日志、识别 `Done (` 就绪行、支持 stdin 指令与 `stop`。
- **界面**：服务端页（状态/端口/Java/内存）、启动/停止、实时控制台、`server.properties` 编辑、EULA 同意。

### 一键汉化（C22）

- 选择汉化补丁 zip → 自动识别 `config/`、`resourcepacks/`、`.minecraft/` 或单一根目录 → 逐文件备份同名文件到 `instances/<id>/backups/l10n-<ts>/` → 覆盖写入。
- 记录写入 `instances/<id>/localizations.json`；支持逐条「撤销」：还原备份 + 删除新增文件 + 清理记录与备份。
- 若压缩包实际是整合包（含 `manifest.json` / `modrinth.index.json`）会拒绝并提示，避免误覆盖。

## 验收过程中发现并修复的问题

0. **`modrinth_search` 参数不匹配（用户实测发现）**：前端按 camelCase 发送 `projectType/gameVersions`，而 `SearchQuery` 是 snake_case，Serde 反序列化报 `missing field project_type`。已给 `SearchQuery` 加 `#[serde(rename_all = "camelCase")]`，并新增单元测试与 C28（用真实 payload 走 serde+HTTP 边界）。此前 UI 测试用 mock IPC，掩盖了该问题，属于测试盲区。\n0b. **发布版窗口打不开（用户实测发现）**：`cargo build --release` 不会启用 Tauri 的 `custom-protocol`，窗口去连 `localhost:5173`（dev 服务器）→ `ERR_CONNECTION_REFUSED`。此前的"验证"只覆盖了 `--self-test`（开窗前退出）与无头前端，**没有真正加载打包后的窗口**，属于测试盲区。已改用 `pnpm tauri build --no-bundle` 构建，并新增 `C27`：隐藏窗口加载 `tauri://` 资源 + 校验标题，作为回归项。

1. **版本继承链合并方向错误**：`flatten_chain` 从子到父合并，导致 Fabric/Forge 启动时 `mainClass` 回退为原版；已修复（父→子），验证 `mainClass=KnotClient` / `BootstrapLauncher`。
2. **Forge 安装器临时目录被拒绝**：为安装器进程注入 `-Djava.io.tmpdir` 与 `TEMP/TMP`，安装成功。
3. **CLI 未使用 `--instance` 名称**：实例 ID 与预期不一致；已修复。
4. **资源包/光影被加载器过滤**：非 Mod 类型不再按加载器过滤版本。
5. **数据目录不可写**：新增 `resolve_writable()` 多级回退（APPDATA → LOCALAPPDATA → exe 同级 → cwd）。
6. **Tauri 窗口在配置中创建失败时无诊断信息**：改为 setup 内自建窗口并输出明确日志。

## 环境限制（非产品缺陷）

1. 沙箱禁止写 `%APPDATA%` / `%LOCALAPPDATA%` → 启动器回退到可执行文件同级 `MICA-Data`；正常桌面环境优先 `%APPDATA%\MICA`。
2. WebView2 在此沙箱无法创建（命名管道受限）→ 通过计划任务在用户会话启动验证窗口与标题；UI 截图用 Chromium 渲染同一构建产物。
3. 无 GPU/显示上下文，游戏在 OpenGL 初始化处退出；`Setting user:` / `Loading Minecraft` 标记证明 JVM、classpath、libraries、assets、加载器均已正确初始化。
4. Adoptium（GitHub）下载被限速 → 自动安装优先使用 Mojang 运行时 CDN，Adoptium 作为兜底。
5. NeoForge 官方 Maven 在本网络 DNS 不可达 → 已提供 installer 拖入路径并验证导入链路。
