## 1. CurseForge 接入

**原因**：CF 标签页为壳，用户要求可搜索/下载/整合包安装。

- 新增 `src-tauri/src/curseforge.rs`：project / files / file / files_by_ids / download_url / search
- 设置项 `curseforgeApiKey`（也支持 `CURSEFORGE_API_KEY` 环境变量，本机保存、不进日志）
- Tauri 命令：`cf_project` / `cf_files` / `cf_search` / `cf_key_status` / `cf_install_mod`
- CLI：`cf-key` / `cf-project` / `cf-files` / `cf-file` / `cf-download` / `cf-batch` / `cf-search` / `cf-install-mod`
- CF 整合包安装：`manifest.json` → 批量文件 → 下载 + SHA1 → `overrides/`
- 下载直链为空时按 PCL 的做法推导 `edge.forgecdn.net/files/{id/1000}/{id%1000}/{name}`
- 前端：下载页 CurseForge Tab（搜索/详情/文件/安装）、设置页 Key 输入、Modrinth 空结果可跳转 CF 搜索

**验证**：`scripts/verify-cf.ps1` → C29–C32 4/4；`Project Infinity` 19 条、`jei` 435 条；JEI 下载 SHA1 与 API 一致。

## 2. Forge 整合包启动崩溃（退出码 1，无日志）

**原因**（命令行复现）：
1. 合并版本 JSON 时库去重键缺少 classifier，导致 `lwjgl` 主 jar 被 natives 覆盖 → `Module org.lwjgl not found`
2. Forge 安装生成 `client-extra` jar，但启动仍用原版 `1.20.1.jar` → 模块重复导出（`_1._20._1` 与 `minecraft`）

**修复**：`version.rs` 去重键加入 classifier；`launch.rs` 对 Forge 优先使用 `client-extra` jar，并按架构过滤 natives。

**验证**：直接用生成的 argfile 启动 Project Infinity 0.1，持续运行 25 秒不退出、`latest.log` 生成、378 个 mod 加载完成、无 FindException/ResolutionException。
